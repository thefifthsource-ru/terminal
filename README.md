# 🖥️ THE FIFTH SOURCE — терминал промптов

**Локальная база русскоязычных промптов для нейросетей.** Один HTML-файл, работает офлайн, без рекламы и регистрации.

### 👉 [**Открыть терминал**](https://thefifthsource-ru.github.io/terminal/)

---

## Что это

Интерактивный терминал с базой готовых промптов для ChatGPT, Claude, DeepSeek и других языковых моделей. Всё собрано в одном файле — открыл в браузере и пользуешься. Интернет нужен только чтобы скачать.

Один из продуктов Telegram-канала [The Fifth Source](https://t.me/TheFifthSource) — про инструменты, находки и открытые данные.

## Что внутри

- **172 промпта** в 12 категориях
- Категории **по задачам**, а не по инструментам:
  - Разработка · Карьера · Бизнес · Финансы · Здоровье
  - Обучение · Творчество · Быт и досуг · Работа с текстом
  - Данные и аналитика · Промптинг · Разное
- Каждый промпт — с тегами для поиска

## Команды

| Команда | Что делает |
|---|---|
| `/help` | Список всех команд |
| `/list` | Все категории |
| `/list <кат>` | Промпты в категории (по 15 на страницу) |
| `/show <id>` | Полный текст промпта |
| `/copy <id>` | Скопировать промпт в буфер |
| `/search <слово>` | Поиск по названию, тексту и тегам |
| `/random` | Случайный промпт |
| `/about` | О проекте |
| `/donate` | Поддержать проект |
| `/clear` | Очистить экран |

## Удобства

- **Клики мышкой** — по категориям, промптам и кнопке «копировать»
- **Tab** — автодополнение команд
- **↑ / ↓** — история команд
- **Работает офлайн** — скачай `index.html` и открывай локально

## Как запустить локально

Скачай [`index.html`](https://github.com/thefifthsource-ru/terminal/blob/main/index.html) и открой двойным кликом в браузере. Всё.
